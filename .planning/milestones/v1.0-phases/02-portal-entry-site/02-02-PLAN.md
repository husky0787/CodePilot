  <name>Task 1: 创建 localStorage 工具库和 Cloud 组件</name>
  <files>apps/site/src/lib/sandbox-storage.ts, apps/site/src/components/cloud/ApiKeyForm.tsx, apps/site/src/components/cloud/SandboxLauncher.tsx, apps/site/src/components/cloud/SandboxRestore.tsx</files>
  <action>
1. 创建 `apps/site/src/lib/sandbox-storage.ts`：
   - 定义 `interface SavedSandbox { sandboxId: string; url: string; createdAt: number; }`
   - 常量 `STORAGE_KEY = 'codepilot-cloud-sandbox'`
   - 导出 `saveSandbox(info: SavedSandbox): void` — `localStorage.setItem(STORAGE_KEY, JSON.stringify(info))`
   - 导出 `loadSandbox(): SavedSandbox | null` — parse localStorage，catch 返回 null
   - 导出 `clearSandbox(): void` — `localStorage.removeItem(STORAGE_KEY)`

2. 创建 `apps/site/src/components/cloud/ApiKeyForm.tsx`（'use client' 组件）：
   - Props: `onSubmit: (apiKey: string) => void`，`disabled?: boolean`，`error?: string`
   - 使用 shadcn Input + Button 组件
   - 输入框 placeholder: `sk-ant-api03-...`
   - 前端前缀校验：Key 必须以 `sk-ant-` 开头，否则显示格式错误
   - 提交按钮文案："Launch Cloud CodePilot"
   - error prop 不为空时在表单下方显示红色错误提示
   - disabled 时按钮和输入框都禁用（防止重复提交）
   - API Key 输入框 type="password" 隐藏内容

3. 创建 `apps/site/src/components/cloud/SandboxLauncher.tsx`（'use client' 组件）：
   - Props: `sandboxId: string`，`sandboxUrl: string`
   - 组件挂载后立即调用 `saveSandbox({ sandboxId, url: sandboxUrl, createdAt: Date.now() })`
   - 启动进度三步状态机：'creating' -> 'starting' -> 'ready'
   - 进入组件时状态为 'creating'，短暂停留后切到 'starting'
   - 轮询 `/api/sandbox/status?id=${sandboxId}`（每 2 秒一次，最多 30 次）
     - 返回 `{ alive: true, ready: true }` -> 状态切到 'ready'，2 秒后 `window.location.href = sandboxUrl` 跳转
     - 超过 30 次未就绪 -> 显示超时错误和重试按钮
   - 使用 framer-motion 做步骤切换动画
   - 每个步骤显示图标 + 文字描述（如 "Creating sandbox..."、"Starting services..."、"Redirecting..."）

4. 创建 `apps/site/src/components/cloud/SandboxRestore.tsx`（'use client' 组件）：
   - 组件挂载后调用 `loadSandbox()` 检查 localStorage
   - 如果有 savedSandbox，调用 `/api/sandbox/status?id=${savedSandbox.sandboxId}`
     - alive: true -> 显示两个选项："Resume Previous Sandbox" 和 "Create New Sandbox"
     - alive: false -> 调用 `clearSandbox()` 静默清除，不显示任何内容（显示正常新建流程）
   - "Resume Previous Sandbox" 按钮点击后直接 `window.location.href = savedSandbox.url`
   - "Create New Sandbox" 按钮点击后调用 `clearSandbox()` 并触发 `onCreateNew` 回调
   - Props: `onCreateNew: () => void`

注意：API Key 绝不保存到 localStorage（安全优先，per CONTEXT.md 锁定决策）。组件使用已有的 shadcn Button/Input（apps/site/src/components/ui/ 下已有）。

   - Cloud 启动区域：集成 SandboxRestore + ApiKeyForm + SandboxLauncher 三个组件的交互流程

   - 状态：'idle' | 'submitting' | 'launching' | 'error'
   - idle 状态：显示 SandboxRestore（检测旧沙箱）+ ApiKeyForm
   - submitting 状态：ApiKeyForm disabled，调用 POST /api/sandbox/create

   - launching 状态：显示 SandboxLauncher（进度 + 轮询 + 跳转）
   - error 状态：恢复 ApiKeyForm 可输入状态，显示错误

3. 样式：使用 Tailwind CSS，深色背景 + 亮色文字，居中布局，响应式（移动端单列，桌面端适当留白）。与现有 marketing 页面保持品牌一致性但更聚焦于 Cloud 入口功能。

4. 这是一个根级 `page.tsx`（不在 `[lang]` 动态路由下），暂时不需要 i18n，默认英文内容。

注意：不在此页面存储 API Key 到任何持久化存储。页面是 Server Component 包裹一个 'use client' 的 CloudLauncher wrapper。
