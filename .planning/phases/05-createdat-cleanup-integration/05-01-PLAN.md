  <action>

    1. 在 `poll()` 函数内、fetch 调用前，调用 `loadSandbox()` 获取 `createdAt`。已在第 34 行 `saveSandbox()` 存储，此时一定可用。
    2. 构建 URL 时追加 createdAt：
       ```typescript
       const saved = loadSandbox();
       const params = new URLSearchParams({ id: sandboxId });
       if (saved?.createdAt) params.set("createdAt", String(saved.createdAt));
       const res = await fetch(`/api/sandbox/status?${params}`);
       ```
    3. 需要在文件顶部 import 中添加 `loadSandbox`（当前只 import 了 `saveSandbox`）。

    **SandboxRestore.tsx（第 39-40 行区域）：**
    1. `saved` 对象已在 `check()` 函数作用域内（第 26 行 `loadSandbox()` 返回），直接使用 `saved.createdAt`。
    2. 构建 URL 时追加 createdAt：
       ```typescript
       const params = new URLSearchParams({ id: saved.sandboxId });
       if (saved.createdAt) params.set("createdAt", String(saved.createdAt));
       const res = await fetch(`/api/sandbox/status?${params}`);
       ```
    3. 无需额外 import，`loadSandbox` 已在第 4 行导入。
