  <name>Task 1: 安装 e2b SDK 并创建服务端工具库</name>
  <files>apps/site/package.json, apps/site/src/lib/validate-key.ts, apps/site/src/lib/e2b.ts</files>
  <action>
1. 在 `apps/site/` 目录下安装 e2b SDK：`cd apps/site && npm install e2b`

2. 创建 `apps/site/src/lib/validate-key.ts`：
   - 导出 `validateAnthropicKey(apiKey: string): Promise<{ valid: boolean; error?: string }>` 函数
   - 使用 fetch 调用 `https://api.anthropic.com/v1/messages/count_tokens` 端点（免费、轻量）
   - 请求头：`x-api-key`、`content-type: application/json`、`anthropic-version: 2023-06-01`
   - Body：`{ model: 'claude-sonnet-4-20250514', messages: [{ role: 'user', content: 'hi' }] }`
   - 200 → valid: true；401 → '无效的 API Key'；403 → 'API Key 权限不足'；其他 → `验证失败 (${status})`
   - catch 网络错误 → '网络错误，无法验证 API Key'

3. 创建 `apps/site/src/lib/e2b.ts`：
   - 导出常量 `TEMPLATE_ID = '9114lthidrvmoik0fcdw'`（来自 e2b.toml）
   - 导出 `createSandbox(anthropicKey: string): Promise<{ sandboxId: string; url: string }>` 函数
     - 调用 `Sandbox.create(TEMPLATE_ID, { envs: { ANTHROPIC_API_KEY: anthropicKey }, timeoutMs: 3600000 })`
     - 返回 `{ sandboxId: sandbox.sandboxId, url: 'https://' + sandbox.getHost(3000) }`
   - 导出 `checkSandbox(sandboxId: string): Promise<{ alive: boolean; ready: boolean; url?: string }>` 函数
     - try `Sandbox.connect(sandboxId)`，成功后用 `sandbox.getHost(3000)` 获取 host
     - 服务端 fetch `https://${host}/api/health`（带 5 秒 AbortSignal.timeout），ok → ready: true
     - catch → `{ alive: false, ready: false }`

注意：不要安装 @anthropic-ai/sdk（过重，只需一个 fetch 调用验证 Key）。E2B API Key 通过环境变量 `E2B_API_KEY` 自动被 SDK 读取，无需代码中显式传入。

两个 route 都使用 NextRequest/NextResponse（Next.js App Router 约定）。从 `@/lib/validate-key` 和 `@/lib/e2b` 导入工具函数。
