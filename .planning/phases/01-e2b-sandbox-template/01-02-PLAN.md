<task type="auto">
  <name>Task 1: 构建 E2B 沙箱模板</name>
  <files>sandbox/e2b.toml</files>
  <action>
在项目根目录执行 E2B 模板构建：

1. 确认 E2B CLI 已安装：`npx @e2b/cli --version`（如未安装则使用 npx 方式）
2. 在项目根目录执行模板构建命令：
   ```bash
   npx @e2b/cli template build \
     -n "codepilot" \
     -c "/home/user/start.sh" \
     --dockerfile sandbox/e2b.Dockerfile \
     --build-context .
   ```
   注意：`--build-context .` 指定项目根目录为构建上下文，这样 Dockerfile 中的 COPY 命令才能访问 package.json、src/ 等文件。
3. 构建成功后，`e2b.toml` 会自动生成在工作目录中，包含 `template_id`
4. 将生成的 `e2b.toml` 移动到 `sandbox/` 目录（如果不是自动生成在那里的话）
5. 记录 template_id 供后续使用

如果构建失败：
- 检查 E2B_API_KEY 是否已设置
- 检查 Dockerfile 语法错误
- 查看构建日志中的具体错误信息
- 常见问题：npm install 失败（网络）、better-sqlite3 编译失败（缺编译工具）

注意：构建过程可能需要 5-15 分钟，取决于 npm install 和 better-sqlite3 编译时间。
